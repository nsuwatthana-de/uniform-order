# สั่งชุดกีฬาให้ทีม

หน้าเว็บสำหรับกรอกไซส์เสื้อและกางเกงกีฬาของสมาชิกทีม ติดตามการจ่ายเงิน และส่งออกเป็น Excel หรือภาพเพื่อส่งให้ร้าน

## เว็บที่ใช้งานจริง (Firebase)

- ลิงก์: https://uniform-order-da59c.web.app/ ใครมีลิงก์ก็เปิดได้ ไม่ต้องล็อกอิน
- โค้ดอยู่ใน `public/` (`index.html` คือหน้าเวอร์ชันล่าสุด, `fb-runtime.js` เชื่อมกับ Firebase)
- กฎสิทธิ์อยู่ใน `firestore.rules`
- push เข้า `main` แล้ว GitHub Actions จะ deploy ให้อัตโนมัติ (`.github/workflows/firebase-deploy.yml`) ต้องมี secret `FIREBASE_SERVICE_ACCOUNT`

### สิทธิ์
| ข้อมูล | สมาชิก (มีลิงก์) | แอดมิน (ล็อกอิน Google) |
|---|---|---|
| ชื่อ ไซส์ ชื่อหลังเสื้อ สถานะจ่าย | อ่านและแก้ได้ | อ่านและแก้ได้ |
| เบอร์โทร | กรอกได้ แต่เห็นเป็น ••••••xx | เห็นเบอร์เต็ม |
| รูปสลิป | แนบได้ แต่ไม่เห็นรูป | เห็นรูป ลบได้ |
| ลบออเดอร์ / ดูสำเนาข้อมูลย้อนหลัง | ไม่ได้ | ได้ |

แอดมินคืออีเมลที่อยู่ในรายการทั้งใน `firestore.rules` และ `ADMIN_EMAILS` ใน `public/fb-runtime.js` (ต้องแก้ทั้งสองที่)

ระบบบันทึกสำเนาข้อมูลไว้ในคอลเลกชัน `backups` ทุก 10 นาทีที่มีการแก้ไข ถ้ามีคนลบรายชื่อผิด แอดมินกู้คืนจาก Firebase Console ได้

### ทดสอบในเครื่อง
```
firebase emulators:start --only firestore,auth,hosting
```
เปิด http://127.0.0.1:5000/ (หน้าเว็บจะต่อกับ Emulator เองเมื่อเปิดจาก localhost)

## เวอร์ชันเก่า (เก็บในเครื่องเดียว)

`uniform.html` และ `summary.html` ที่ root เก็บข้อมูลในเบราว์เซอร์ของเครื่องนั้นเท่านั้น ไม่ได้ใช้แล้ว
